# Asset Sweep – WordPress Plugin

Remove unused CSS and JavaScript from your WordPress site with simple toggles. Great for Elementor, Divi, and other page-builder sites.

## Quick Install

1. **Download** the latest `asset-sweep.zip` from [Releases](https://github.com/SteveKinzey/Asset-Sweep-Remove-Unused-CSS-JS/releases)
2. **Upload** to WordPress: Plugins → Add New → Upload Plugin
3. **Activate** on your Plugins page
4. **Configure** at Settings → Asset Sweep

## What It Removes

- ✂️ WordPress emoji script and styles
- ✂️ Embeds and oEmbed discovery
- ✂️ Gutenberg block library CSS
- ✂️ Global theme.json styles
- ✂️ jQuery Migrate
- ✂️ Dashicons (logged-out visitors)
- ✂️ Custom script/style handles (your choice)

## Features

**One Toggle Per Optimization** — Enable what you need, leave everything else off.

**Debug Mode** — See every enqueued script and style in View Source (admins only).

**Safe Rollback** — Disable any option instantly. Everything reverts on uninstall.

**Elementor Friendly** — Tested with Elementor, Divi, and standard Gutenberg.

## Performance Impact

Real savings on typical Elementor sites: **88 KB total** = 20–50ms faster page loads.
